# Dragon Ball: Raging Blast 2 - PC Port

A native Windows port of Dragon Ball: Raging Blast 2 (no emulator), with its own launcher, updates, the Raging Blast 1
roster and maps, and mod support.

## ⬇️ [Download the game (version 1.0)](https://github.com/Castlesea/rb2-pc-port/releases/latest)

Open the link above and download **RB2_PC_Port_1.0.zip**, then follow **Installing** below.

## What you need

- Windows 10 or 11 (64-bit). Linux / Steam Deck through Proton should work too.
- A CPU with AVX2 (Intel 4th gen or newer, any AMD Ryzen) and a DirectX 12 GPU.
- **Your own copy of the game:** the Xbox 360 disc image (.iso) of **Dragon Ball: Raging Blast 2 (USA) (Rev 1 / v1.1)**.
  The port does not include the original game's files; the launcher copies them from your disc image.
- About 12 GB of free disk space.

## Installing

1. Download **RB2_PC_Port_1.0.zip** from the latest release and extract it somewhere that's yours, such as
   `C:\Games\Raging Blast 2` (not in Program Files).
2. Open **Raging Blast 2 Launcher.exe**.
3. Press **Select ISO** and choose your Raging Blast 2 (USA) (Rev 1 / v1.1) disc image. The launcher checks it and copies the
   game's files (about a minute).
4. The launcher then downloads the game content by itself (Raging Blast 1 characters and maps, music, interface art).
5. Press **PLAY**.

## Updates

Open the launcher: when there is an update it shows an **Update** button. One press updates the launcher, the game
and its content, downloading only what changed. Your saves, settings and mods are never touched.

Versions 0.9.x are no longer updated: install 1.0 in a new folder.
